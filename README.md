## 🧭 مأموریت و چشم‌انداز CoffeeCodee

آزمایشگاه متن‌باز **CoffeeCodee** با هدف پر کردن شکاف بین مباحث تئوریک و سورس‌کدهای واقعی سطح پروداکشن در اکوسیستم برنامه‌نویسی موبایل پایه‌گذاری شده است. تمرکز اصلی پروژه‌های این سازمان بر ارائه‌ی راهکارهای مقیاس‌پذیر، معماری‌های آزمون‌پذیر (Testable) و کدهای تمیز و بهینه‌سازی‌شده برای مهندسان اندروید است.

### 🎯 حوزه‌های تمرکز پروژه‌ها:
* 🏛️ **معماری تمیز و طراحی ماژولار:** تفکیک مهندسی‌شده لایه‌های Domain ،Data و Presentation به همراه الگوهای Use Case و Repository.
* ⚡ **رابط کاربری مدرن با Jetpack Compose:** پیاده‌سازی کامپوننت‌های واکنشی، State Hoisting و سیستم‌های طراحی سازگار با استانداردهای مدرن.
* 🔄 **الگوهای هم‌روندی پیشرفته:** مدیریت بهینه جریان داده‌ها و استیت‌ها با Kotlin Coroutines و StateFlow بدون نشت حافظه (Memory Leaks).
* 🧪 **پایداری و تست‌پذیری:** الگوهای کاربردی Unit Testing، ایزوله‌سازی مخازن داده و آزمون‌های رفتاری.

## 📚 مراجع علمی و راهنماهای مرجع

سورس‌کدها و تمپلیت‌های معماری این آزمایشگاه بر پایه اصول و نقشه‌های راه مهندسی زیر توسعه داده می‌شوند:

* 📱 **نقشه راه جامع توسعه:** راهنمای گام‌به‌گام یادگیری و تسلط بر استک مدرن در مقاله **[آموزش برنامه نویسی اندروید](https://vahidhoseini.ir/blog/android-programming-complete-roadmap-guide)**.
* 🏛️ **کالبدشکافی معماری تمیز:** تحلیل عمیق تفکیک لایه‌ها، جریان داده یک‌طرفه (UDF) و اصول SOLID در راهنمای **[معماری تمیز در اندروید](https://vahidhoseini.ir/blog/clean-architecture-scalable-systems-guide)**.
* 🎨 **واسط کاربری واکنشی:** الگوهای طراحی کامپوز و سیستم‌های طراحی مدرن در راهنمای **[توسعه رابط کاربری با Jetpack Compose](https://vahidhoseini.ir/blog/jetpack-compose-modern-android-ui-complete-guide)**.

## 🛠️ جعبه‌ابزار و استک فناوری (Tech Stack)

| لایه سیستم | ابزارها و تکنولوژی‌ها |
| :--- | :--- |
| **زبان‌های برنامه‌نویسی** | Kotlin (100% Idiomatic), Java |
| **فریم‌ورک رابط کاربری** | Jetpack Compose, Material Design 3, Navigation |
| **جریان داده و هم‌روندی** | Kotlin Coroutines, StateFlow, SharedFlow, Channels |
| **تزریق وابستگی (DI)** | Dagger Hilt, Koin |
| **لایه داده و شبکه** | Room Database, Ktor Client, Retrofit, Kotlinx Serialization |
| **الگوهای طراحی و معماری** | Clean Architecture, MVI, Repository Pattern, DDD |
| **توسعه چندسکویی** | Kotlin Multiplatform (KMP), Compose Multiplatform |
